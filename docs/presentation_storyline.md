# Presentation Storyline

## 탐지 구조 설명

본 프로젝트의 탐지 구조는 여러 탐지기를 단순히 동시에 실행하는 구조라기보다, 정규식 패턴 계층, 휴리스틱 규칙 계층, 경량 분류 계층을 순차적으로 통과하는 다층형 탐지 파이프라인이다. 정규식 계층은 형식이 명확한 개인정보를 빠르게 탐지하고, 휴리스틱 규칙 계층은 정책 우회나 시스템 프롬프트 탈취와 같은 공격 단서를 판단한다. 경량 분류 계층은 규칙만으로 잡기 어려운 비정형 프롬프트 인젝션을 보완한다.

## 발표 포인트

- 대표 명칭은 다층형 탐지 파이프라인(Multi-layered Detection Pipeline)으로 설명한다.
- 정규식, 휴리스틱 규칙, 경량 분류는 병렬 나열이 아니라 단계적으로 위험 신호를 보강하는 계층이다.
- 최종 Decision Layer는 각 계층의 탐지 결과와 정책 우선순위를 종합해 `ALLOW`, `MASK`, `BLOCK`, `WARN` 조치를 결정한다.
- 기존 코드의 `hybrid_detector.py` 명칭은 구현 호환성을 위한 이름이며, 발표에서는 넓은 의미의 하이브리드 구조라는 보조 설명으로만 사용한다.
