## 수록 기준과 접근 한계

- 정부24·행정안전부·목포시의 공식 자료만 사용했다. 신규 확인일은 2026-11-03이며 기존 10건의 확인일은 유지했다. 원문 전체나 법령 최신성을 재검증한 것으로 표현하지 않는다.
- `page_text`는 해당 업무 본문을 확인한 자료이고 `official_search_extract`는 공식 도메인의 검색 추출문으로 대조한 자료다. 일부 정부24 URL은 직접 열 때 접근 안내·메뉴만 보이므로 검색 추출문과 구분해 기록했다.
- 인감 신규 신고·변경·증명서 발급을 나누고, 장애인 등록과 증명서 발급, 수급자 증명과 급여 신규 신청도 별개 업무로 등록했다.
- 지방세 납세증명과 세목별 과세증명을 구분한다. 지방세 자료를 국세 서류로 대체하지 않는다. 지방정부 조례의 수수료를 전국 단일 금액으로 바꾸지 않는다.
- 복지 신청은 접수 경로와 기본 증빙 범위의 안내다. 자격 심사·지급액 계산·신청 완료를 제공하지 않는다. 실제 서류 제출과 채팅 입력은 다르므로 계좌·소득·의료기록을 채팅으로 받지 않는다.
- 보육료 공식 페이지에는 과거 카드명·종일반 관련 서식 표현이 남아 있다. 이를 현재 필수서류로 전재하지 않고 최신 상세 요건을 담당기관 확인으로 남겼다.
- 임신 통합서비스는 목포시 자료만 대조했으므로 다른 지역에 지원품목·담당 창구를 그대로 적용하지 않는다.
- 자동 수집·자동 갱신·벡터 검색·법령 API는 추가하지 않았다. 기존 키워드 검색·입력 검사·마스킹·출력 Validator를 사용한다. 자료 로드 캐시 반영에는 서버 재시작이 필요하다.

## 추가로 발견한 로그 문제

새 검사에서 한국어 공격 문장의 일부 또는 전체가 `input.prompt_injection.matched_terms`로 감사 로그에 남을 수 있음을 재현했다. 저장 전 재귀 정리에서 `matched_terms`와 `matched_text`를 제외했다. 정책 action·reason code·분류·건수·서명 구조는 유지한다. 기존에 저장된 로그는 자동 삭제·정리하지 않았다. 모든 가능한 메타데이터 필드의 원문 유출을 증명한 검사는 아니다.

실제 실행 결과와 최초 실패 기록은 [확대 검증 보고서](../reports/resident_center_expansion_verification.md), 변경·후속 범위는 [Codex 기록](codex_resident_center_expansion.md)을 따른다.
