LLM Security Proxy Demo

백엔드 보안 프록시의 사용자 입력 흐름과 관리자 요약을 한 화면에서 보여주는 발표용 정적 데모 페이지입니다. FastAPI 프록시가 http://127.0.0.1:8000에서 실행 중일 때 사용할 수 있습니다.

사용자 입력

프롬프트를 입력하고 `policy_id`를 선택한 뒤 프록시 요청을 실행합니다.

결과 화면

프록시의 최종 action과 reason_code, 응답 본문, audit 요약을 확인합니다.

READY
아직 요청이 실행되지 않았습니다.
{
  "action": "ALLOW | MASK | WARN | BLOCK | ERROR",
  "reason_code": null,
  "content": null
}

관리자 요약

관리자 토큰으로 `/admin/stats`와 `/admin/reason-codes`를 조회합니다.

총 요청
-
차단 / 마스킹 / 경고
-
아직 조회되지 않았습니다.

최근 차단 이력

최근 차단된 요청의 request_id와 reason_codes를 빠르게 확인합니다.

아직 조회되지 않았습니다.
