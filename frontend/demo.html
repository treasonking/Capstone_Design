LLM Security Proxy Demo

백엔드 보안 프록시의 사용자 입력 흐름과 관리자 요약을 한 화면에서 보여주는 발표용 정적 데모 페이지입니다. FastAPI 프록시가 http://127.0.0.1:8000에서 실행 중일 때 사용할 수 있으며, API 호출까지 함께 확인하려면 http://127.0.0.1:5500/demo.html로 서빙하는 구성을 권장합니다.

프롬프트를 입력하고 `policy_id`를 선택한 뒤 프록시 요청을 실행합니다.

사용 주의

본 페이지는 캡스톤 발표 및 로컬 검증용 정적 데모 페이지이며, 운영용 관리자 콘솔이 아니다. API Key, Authorization 헤더, 원문 로그 저장 기능은 포함하지 않으며, 관리자 토큰은 브라우저 저장소에 저장하지 않습니다.
