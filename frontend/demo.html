하이브리드 보안 게이트웨이

정규표현식 기반 PII 탐지, 룰 기반 Prompt Injection 탐지, 경량 문장 분류 모델을 결합해 입력과 출력을 함께 검사합니다. 실무자는 차단 사유를 바로 이해하고, 관리자는 원문 미저장 원칙 아래 정책과 로그를 점검할 수 있습니다.

정책 결과

최종 액션은 `ALLOW / WARN / MASK / BLOCK`으로 정리되며, 입력과 출력 중 더 강한 조치가 사용자 응답에 반영됩니다.

감사 로그 원칙

본 시스템은 원문 프롬프트/응답 전문을 저장하지 않습니다. 차단 사유, detector count, latency, masked preview만 남깁니다.

실행 대상

FastAPI 프록시가 http://127.0.0.1:8000에서 실행 중일 때 입력 흐름, 관리자 통계, 정책 스냅샷을 한 화면에서 확인할 수 있습니다.

사용자 요청

프롬프트를 입력하고 정책 모드를 선택한 뒤 프록시 요청을 실행합니다. 예시 버튼으로 `안전`, `마스킹`, `차단` 상황을 바로 확인할 수 있습니다.

탐지 결과

사용자에게는 상태 배지, 한글 사유, 탐지된 개인정보 유형, 안전한 preview를 우선 보여주고 필요할 때만 raw JSON을 펼쳐볼 수 있도록 구성했습니다.
