# Final Improvement Summary

본 프로젝트는 초기 정규표현식 기반 개인정보 탐지 구조에서 출발했으나, 멘토 피드백을 반영하여 정규표현식, 정책 룰, 경량 문장 분류 모델을 결합한 하이브리드 탐지 구조로 개선하였다.

정규표현식은 주민등록번호, 전화번호, 이메일, 카드번호처럼 형식이 명확한 개인정보를 빠르고 설명 가능하게 탐지하는 역할을 담당한다. 정책 룰은 보안 정책 무시, 시스템 프롬프트 탈취, 역할 탈옥, 원문 유출 유도 등 명확한 프롬프트 인젝션 공격을 차단한다. 경량 모델은 정규식과 룰만으로 판단하기 어려운 문맥 기반 위험 문장을 보조적으로 분류한다.

또한 내부 작성 데이터만으로 평가할 경우 특정 룰과 문장 패턴에 과적합될 가능성이 있으므로, 공공기관 업무 시나리오를 반영한 합성 데이터셋을 `safe`, `pii_risk`, `injection_risk`, `mixed_risk`, `edge_case`로 구성하고 학습/검증/테스트를 분리하는 구조를 추가하였다. 평가 스크립트는 `regex`, `rule`, `model`, `hybrid` 모드를 각각 실행해 비교 리포트를 남기도록 설계했다.

최종적으로 본 시스템은 단순 LLM 프록시가 아니라 공공기관 실무자가 정책을 설정하고, 탐지 결과를 이해하며, 원문을 저장하지 않는 감사 로그를 통해 보안성과 사용성을 함께 확보하는 LLM 보안 게이트웨이를 목표로 한다.
