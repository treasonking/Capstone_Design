- Ollama 모델 `qwen2.5:1.5b`, 연결 상태 `ready`, 워밍업 `completed`

- 경량 분류기 상태 `enabled`, 운영 임계치 `0.7`, 라우팅 폭 `0.1`
- 표시된 지연은 준비된 케이스의 프록시 입력 검사·정책·송신 준비 시간이다. HTTP 프록시·외부 생성·Validator Agent·로그 I/O는 포함하지 않는다.
- Ollama 평균은 추론 API 호출이 시작된 요청의 모델 확인과 추론을 포함한다. CPU/RAM/VRAM 자동 수집은 N/A이며 별도 프로세스 표본은 [평가 실행 환경](../docs/ollama_adaptive_detection.md#평가-실행-환경)에 기록했다.
- 탐지 표는 작업별 이진 플래그 비교다. 장애 차단은 별도 운영 결정이다. Ollama Only의 실패가 있으면 해당 코호트의 탐지 지표는 N/A이며 JSON에 채점 범위가 포함된다.
- 양성만 포함한 Lakera 표에서 Precision·F1·FPR은 N/A다. 외부 표는 저장소의 공개 데이터셋 부분집합에 한정된다.
- 송신 검증은 정책과 송신 가드의 결과를 메모리에서 관찰했다. 실제 외부 네트워크 호출은 0건이다. 합성 검증의 유출률은 정답 문자열이 포함된 양성 요청 대비 최소 하나가 송신될 비율이다. 마스킹 성공률·실패율은 마스킹 후 송신된 정답 양성 요청 기준이다.
- 내부 및 합성 결과는 회귀 확인용이다. 원문·정답 문자열·모델 자유 텍스트는 결과 파일에 저장하지 않는다.
